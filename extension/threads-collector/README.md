# 선물노트 스레드 수집기 (초기 버전)

Threads 화면에서 게시물을 자동으로 찾고 각 게시물 오른쪽에 작은 북마크 아이콘과 조회·좋아요 수를 표시합니다. 아이콘을 누르면 `수집하기`가 열리며, 사용자가 선택한 게시물만 Chrome 로컬 저장소에 보관합니다. 화면에서 조회수를 제공하지 않는 게시물은 `조회 —`로 표시합니다.

게시물 하나에 여러 개의 시간·미디어 링크가 있어도 Threads 게시물 ID를 기준으로 수집 버튼과 팝업 항목을 하나로 합칩니다.

## 설치 (개발용)

1. `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더 `extension/threads-collector`를 선택합니다.
5. Threads의 게시물 목록을 열면 각 게시물 오른쪽에 수집 아이콘과 반응 수가 나타납니다. 중복 설치를 피하려고 기존 선물노트 수집기 확장 프로그램이 있으면 하나만 남겨주세요.
6. 참고할 글 옆 아이콘을 눌러 **수집하기**를 누릅니다. 확장 프로그램 팝업에서도 저장 결과를 확인할 수 있습니다.

저장 자료는 이 Chrome 프로필 안에 남습니다. **저장한 자료 내보내기**로 JSON 파일을 받을 수 있습니다. 확장 프로그램은 게시물 자동 좋아요·팔로우·댓글·재게시를 하지 않습니다. 공개 게시물이라도 원문을 재게시하지 말고, Gemini에는 구조와 말투 참고 자료로만 사용하세요.

이 초기 버전은 Threads 페이지 구조가 바뀌면 게시물을 찾지 못할 수 있습니다. 조회수와 좋아요는 DOM에서 직접 읽을 수 있는 표시만 수집하며, 비공개·숨김 정보를 가져오지 않습니다. 아직 선물노트 웹사이트의 저장한 초안과 자동 동기화되지는 않습니다.
