# 선물노트 스레드 수집기

확장프로그램 ID는 manifest의 고정 공개 키로 유지됩니다. 이 `key`를 삭제하거나 새 키로 바꾸면 Chrome이 다른 저장소를 만들 수 있으니 버전 업데이트 때 그대로 유지해야 합니다. 업데이트할 때는 기존 확장프로그램을 제거하지 말고 같은 폴더의 파일을 교체한 뒤 확장프로그램 새로고침을 누르세요. 삭제하면 Chrome이 로컬 수집 자료를 지울 수 있습니다.

v0.7.0에서 고정 ID를 처음 도입했습니다. 이 버전으로 한 번 전환한 뒤부터는 같은 ID와 저장소를 사용합니다. 기존 ID의 Chrome 저장소에서 이전 수집 데이터가 이미 지워진 경우에는 자동 복구할 수 없습니다.

Threads 화면에서 게시물을 자동으로 찾고 각 게시물 오른쪽에 작은 북마크 아이콘과 조회·좋아요 수를 표시합니다. 아이콘을 누르면 `수집하기`가 열리며, 사용자가 선택한 게시물만 Chrome 로컬 저장소에 보관합니다. 화면에서 조회수를 제공하지 않는 게시물은 `조회 —`로 표시합니다.

게시물 하나에 여러 개의 시간·미디어 링크가 있어도 Threads 게시물 ID를 기준으로 수집 버튼과 팝업 항목을 하나로 합칩니다.

## 설치 (개발용)

1. `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더 `extension/threads-collector`를 선택합니다.
5. Threads의 게시물 목록을 열면 각 게시물 오른쪽에 수집 아이콘과 반응 수가 나타납니다. 중복 설치를 피하려고 기존 선물노트 수집기 확장 프로그램이 있으면 하나만 남겨주세요.
6. 참고할 글 옆 아이콘을 눌러 **수집하기**를 누릅니다. 확장 프로그램 팝업에서도 저장 결과를 확인할 수 있습니다.

저장 자료는 이 Chrome 프로필 안에 남습니다. 선물노트 사이트의 `수집한 스레드` 메뉴도 이 Chrome 저장소를 읽어 자동으로 갱신됩니다. 첫 설치나 업데이트 뒤에는 확장 프로그램을 다시 불러오고, 사이트 탭도 새로고침하세요. **저장한 자료 내보내기**로 JSON 파일을 받을 수 있습니다. 확장 프로그램은 게시물 자동 좋아요·팔로우·댓글·재게시를 하지 않습니다. 공개 게시물이라도 원문을 재게시하지 말고, Gemini에는 구조와 말투 참고 자료로만 사용하세요.

Threads 페이지 구조가 바뀌면 게시물을 찾지 못할 수 있습니다. 조회수와 좋아요는 화면에서 직접 읽을 수 있는 표시만 수집하며, 비공개·숨김 정보를 가져오지 않습니다. 수집 데이터는 같은 Chrome 프로필의 확장프로그램 저장소와 선물노트 사이트 사이에서만 전달됩니다. Gemini 글 생성 연동은 아직 포함하지 않습니다.
