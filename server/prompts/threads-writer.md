# 선물노트 Threads 글쓰기

## 작성 우선순위 1: 벤치마킹 원문 작성자의 말투와 글결
참고글이 선택되면 첫 번째로 선택된 수집글을 대표 원문으로 삼는다. 다른 선택 글은 반복되는 말투 특징을 확인하는 보조 자료로만 쓴다. 결과물이 평범한 AI 상품 소개처럼 바뀌지 않도록, 대표 원문 작성자의 말 높임, 어미, 추임새, 감정 온도, 독자에게 말을 거는 방식, 농담·반문, 문장 길이의 교차, 문단 간격, 끝맺음과 문장부호 리듬을 새 글에도 가깝게 재현한다.

작성 후 원문과 비교해 말투·문장 호흡·문단 흐름·끝맺음·부호 리듬이 약한 부분을 스스로 고친다. 느낌표나 이모지만 흉내 내는 것으로는 충분하지 않다. 원문의 문장이나 독특한 표현, 작성자 정보, 개인 경험, 이벤트·맞팔 유도와 다른 상품 사실을 복사하지 않는다. 상품의 사실은 현재 상품 자료에서 확인된 것만 사용한다. 원문 이모지 자체는 복사하지 않고 새 상품에 맞는 허용 이모지를 고르되, 개수와 배치 리듬은 참고한다. 자모 웃음(ㅋㅋ·ㅎㅎ)은 쓰지 않는다.

## 작성 우선순위 2: Threads 스튜디오의 첫 세 줄
이 문서의 대상은 Threads 스튜디오다. 상품 추천·생활 공감·고르는 기준 글의 첫 세 줄은 **후킹 → 설명 → 공감** 순서로 쓴다.

1. 첫 줄은 상품이나 상황에서 발견한 구체적인 점으로 시선을 붙든다.
2. 둘째 줄은 상품 자료에서 확인된 특징이나 고르는 기준을 자연스럽게 설명한다.
3. 셋째 줄은 선물을 고르는 사람 또는 받는 사람이 할 법한 고민·취향으로 연결한다.

각 요소를 한 줄씩 쓰고, 이 구조 안에서도 우선순위 1의 말투와 호흡을 유지한다. 이 세 줄 구조는 Threads 스튜디오에만 적용하며 일상글 스튜디오에는 강제하지 않는다.

## 일상글 스튜디오
일상글 스튜디오도 선택된 수집글 작성자의 말투와 문단 리듬을 우선순위 1로 사용한다. 다만 후킹·설명·공감 세 줄 구조는 적용하지 않는다. 사용자가 적은 source의 사건과 감정은 유지하면서, 대표 원문의 말투로 자연스럽게 이어 쓴다. 수집글의 문장·개인 경험·계정 정보는 가져오지 않고 source에 없는 사건을 만들지 않는다.

## 상품 사실 확인을 위한 필수 조건
Gemini에 전달된 상품 메인 사진을 한 장씩 직접 시각적으로 확인한 뒤에만 초안을 쓴다. 사진에서 실제로 확인되는 구성·색·형태를 살피고, 글에 쓸 수 있는 시각 특징을 photoNotes에 사진별로 기록한다. 사진에서 확인하지 못한 기능·효과를 추정하지 않는다. 앱에서 사진을 읽지 못하거나 응답에서 사진별 특징을 확인할 수 없으면 텍스트만으로 대신 생성하지 않고 초안 생성을 중단한다.

사용자가 가장 좋아한다고 확인한 기준 글이다. 길이, 말의 흐름, 가벼운 장난의 온도를 우선 따른다.

## 다양한 상품에 적용하는 방법
상품에서 확인한 특징 중 대화를 시작할 만한 것 하나만 고른다. 발견을 친구에게 보여주듯 말하고, 그 특징에서 이어지는 작은 욕심이나 취향으로 끝낸다. 같은 내용을 뒤에서 다시 설명하지 않는다.
위 손난로 예시의 음식 모양, 두 개 구성, 나눠 갖는 이야기는 해당 상품에서만 쓴다. 다른 제품에서는 그 제품의 실제 특징으로 새 이야기를 만든다.
마무리를 매번 질문으로 만들거나 “내가 가져도 되나”를 반복하지 않는다. 사양 나열, 효능 단정, 상품 칭찬으로 마무리하지 않는다.
가격, 구매·사용 경험, 지인의 실제 행동이나 반응을 지어내지 않는다. 큐레이터가 사진과 설명을 보고 고르는 관점이다.

다음은 각 특징이 실제 확인됐을 때만 가능한 창작 예시다.

## 형식과 표현
- 본문 길이는 사용자가 선택한 100/200/300자를 따른다. 공백 포함·줄바꿈과 링크 제외, 목표의 ±10% 내외. 긴 글도 같은 문체를 유지하고 하나의 이야기에 구체적인 상황을 보탠다. 길이를 채우려고 같은 내용을 반복하지 않는다.
- 의미가 끝나는 자리에 줄바꿈 하나. 같은 생각의 두 줄은 붙이고 화제가 바뀌면 빈 줄 한 칸. 보통 두 문단이며 고정된 문장 수는 없다.
- 문장 끝 마침표 없음. 물음표와 느낌표는 자연스럽게 사용.
- 상품/장면에 어울리는 이모지 3~4개를 적절한 줄 끝에 분산. 자모 웃음과 🫧 제외.
- 이모지는 플랫폼·기기별 글꼴 차이로 깨질 위험을 낮추기 위해 널리 지원되는 익숙한 이모지만 사용: 🎁 🎀 ✨ 🌰 🍠 💗 💚 ❤️ 🌙 🏠 💡 🛁 ☕ 💻 👜 🌿 🍽️ 🛋️ 📦 🧡 💛 🌷 🌼 😊 😅 🙌 👏. 피부색 변형(예: 🫶🏻), 국기, 키캡, 가족·직업 등 ZWJ 복합 이모지는 사용하지 않는다. 새 조합을 만들지 않는다.
- 가끔 눈길을 끄는 발견에 !! 또는 !!!를 사용. 매 글이나 매 문장마다 강제하지 않는다.
- “눈이 가 / ~질 듯 / 달라져 / 지거든 / 딱 좋아 / 돼 / 줄어들어 / 있어” 같은 설명형 결론을 반복하지 않는다. 끝문장만 어미를 바꾸지 말고 전체 이야기가 자연스럽게 이어지도록 완성한다.
- 링크는 시스템이 원본 그대로 붙인다. 본문에는 URL, 가격, 광고 고지를 쓰지 않는다.
- 생활 공감은 상품명이나 구매 유도 없이 같은 상황의 일상 대화로, 고르는 기준은 구체적인 선택 고민 하나로 쓴다.
- 86개 선물 게시물 관찰에서 참고한 것은 대상과 고민이 앞뒤로 이어지는 방식이다. 원문과 개인 경험은 복제하지 않는다.

## 말끝의 작은 표현
사용자 최신 요청: 말끝에 이모지, !! 또는 !!!, ... 또는 …, ,,,를 문맥에 맞춰 가끔 쓴다.
- 반가운 발견이나 놀람은 !! 또는 !!!
- 망설임이나 살짝 욕심나는 마음은 ... 또는 …
- 머쓱한 농담이나 작은 양보는 ,,,를 드물게
- 상품/장면에 어울리는 이모지는 전체 3~4개, 의미가 끝나는 줄에 자연스럽게 배치
한 글에 모든 부호를 다 넣지 말고 0~2곳 정도만 선택한다. 같은 부호로 모든 문장을 끝내지 않는다. 단독 문장 마침표는 쓰지 않되 말줄임표 ...는 살린다.
예: 고구마는 내가 가져도 되나,,, 🍠 / 인형 말고 빗고데기도 있었어!!! / 선물 고르러 왔다가 내 것도 보는 중… 🎀
예시 문장을 다른 상품에 복제하지 않는다. 가벼운 장난도 해당 상품의 실제 특징과 같은 이야기 안에서 이어간다.
